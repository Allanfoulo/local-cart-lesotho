# Visual direction

Use the supplied Mabote Fresh reference: warm cream canvas, green primary actions, dark readable text, product photography, generous touch targets and compact shopping-first layouts. The user is shopping on a phone in bright daylight; the light theme supports that setting.

Use existing OKLCH tokens. Product cards use a restrained border and a photo above name, explicit price unit, availability and an add/quantity control. Desktop uses five columns; phone uses two. Admin uses a left sidebar, plain tables, clear status labels and editable forms. Respect reduced motion and keyboard focus. System sans-serif keeps loading lightweight.
