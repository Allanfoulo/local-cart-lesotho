# REETAPELE app icon concepts

Editable SVG concept marks for the app icon, using the current green, cream, and orange identity.

- `concepts/` contains the three original directions.
- `flag-variants/` contains six versions with progressively stronger use of Lesotho flag blue, white, green, and black. Variant 6 uses the most flag-forward layout.
- `liquid-glass/` contains the three liquid-glass studies from the previous comparison.
- `3d-ideas/` contains six new studies: soft clay, enamel medallion, isometric delivery crate, clear glass panes, frosted glass colors, and prismatic glass.
- `pwa/` contains the selected emerald-glass artwork as 192px, 512px, and maskable SVG icons. The root `manifest.webmanifest` points to these assets.

The approved direction can be exported into the required PWA sizes and connected to the app manifest after selection.
